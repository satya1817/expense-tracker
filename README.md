# ⚡ Stark Finance - Expense Tracker

A full-stack Expense Tracker web application inspired by Marvel's JARVIS interface.

## 🚀 Features

* User Registration & Login
* JWT Authentication
* Protected Routes
* Add Transactions
* Edit Transactions
* Delete Transactions
* Search Transactions
* Filter by Income/Expense
* Expense Analytics with Pie Charts
* Marvel-inspired JARVIS UI
* Intro & Outro Video Animations
* Responsive Design

## 🛠 Tech Stack

### Frontend

* React.js
* Axios
* React Router DOM
* Recharts
* CSS

### Backend

* Node.js
* Express.js
* MongoDB Atlas
* Mongoose
* JWT Authentication
* bcryptjs

## 🌐 Deployment

* Frontend: Vercel
* Backend: Render
* Database: MongoDB Atlas
